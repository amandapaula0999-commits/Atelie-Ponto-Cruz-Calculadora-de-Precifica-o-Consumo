# Atelie-Ponto-Cruz-Calculadora-de-Precifica-o-Consumo
Uma aplicação web artesanal e inteligente criada para ajudar artesãos de Ponto Cruz a calcular exatamente quanto cobrar por cada peca ou chaveiro, estimando automaticamente o consumo de linha (meadas), cola de silicone, tecido étamine e tecido de acabamento.  Nota / Adendo: Esse projeto foi feito com a ajuda de IA.
